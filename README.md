# 🧳 AI Packing Assistant - Smart Travel Packing Based on Weather

The **AI Packing Assistant** is a smart web-based chatbot that helps travelers generate personalized packing lists based on their destination, travel dates, trip type, gender, and local weather conditions.

![Demo](travel_packing.jpeg)

---

## ✨ Features

- 🗺️ User-friendly chatbot interface
- 🌤️ Real-time weather integration using **OpenWeatherMap API**
- 🎒 Intelligent suggestions based on:
  - Destination & weather
  - Trip type (e.g. Beach, Business, Adventure)
  - User’s gender
- ✅ Avoids overpacking and ensures essentials are never missed
